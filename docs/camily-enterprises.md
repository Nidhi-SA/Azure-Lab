# Guided Project: Set Up New Employee Access (Entra ID & RBAC)

## Overview
This guided project simulates a real-world scenario at **Camily Enterprises (https://camily.ai)**, where a new employee needs access to Azure resources. The task focuses on identity management and role-based access control (RBAC) using Microsoft Entra ID.

## Learning Objectives
- Create a user and security group in Microsoft Entra ID
- Assign group-based Azure RBAC at the resource group scope
- Validate expected access at the correct scope
- Clean up users, roles, and resources to avoid leftovers

## Steps Performed
### 1. Created a new user in Microsoft Entra ID
### 2. Created a security group
### 3. Assigned RBAC at resource group scope
### 4. Validated access
### 5. Cleaned up resources
