# Monitoring Lab

## Overview
This lab focuses on monitoring Azure resources using Azure Monitor, metrics, logs, and alerts. The goal is to understand how to track performance and detect issues.

## Tasks Completed
- Enabled Azure Monitor for resources
- Viewed metrics such as CPU, disk, and network
- Configured alerts for critical thresholds
- Checked Activity Log and Log Analytics

## Steps Performed

### 1. Viewed Metrics
- Opened VM metrics
- Checked CPU usage, disk I/O, and network traffic

### 2. Created Alerts
- Set conditions (e.g., CPU > 80%)
- Configured action groups (email notifications)

### 3. Checked Logs
- Viewed Activity Log for resource events
- Ran basic queries in Log Analytics Workspace

### 4. Verified Alerts
- Triggered test conditions
- Confirmed alert notifications were received

## Verification
- Metrics displayed correctly
- Alerts triggered as expected
- Logs showed accurate resource events
