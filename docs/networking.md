# Networking Lab

## Overview
This lab focuses on creating and configuring core Azure networking components such as virtual networks, subnets, and network security rules. The goal is to understand how resources communicate securely within Azure.

## Tasks Completed
- Created a Virtual Network (VNet)
- Added one or more subnets
- Assigned private IP addresses to resources
- Configured Network Security Group (NSG) rules
- Tested connectivity between resources

## Steps Performed

### 1. Created a Virtual Network
- Selected region
- Defined address space (e.g., 10.0.0.0/16)

### 2. Added Subnets
- Created subnets for different workloads
- Assigned appropriate IP ranges

### 3. Configured NSG Rules
- Allowed required inbound traffic (RDP/SSH)
- Blocked unnecessary ports
- Verified rule priority and direction

### 4. Tested Connectivity
- Connected to VMs
- Verified communication between subnets
- Confirmed NSG rules were applied correctly

## Verification
- Successful ping/connection tests
- NSG rules enforced expected behavior
