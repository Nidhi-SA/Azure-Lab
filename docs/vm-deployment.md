# Virtual Machine Deployment Lab

## Objective
Deploy and configure a virtual machine in Azure.

## Tasks Completed
- Created a Windows/Linux VM
- Selected region, size, and image
- Configured admin username/password or SSH key
- Set up networking (VNet, subnet, NSG)
- Connected using Bastion or RDP/SSH

## Verification
- VM shows "Running"
- Successful remote connection
