# Storage Lab

## Overview
This lab explores Azure Storage Accounts and how to manage data using containers, blobs, and access tiers. The goal is to understand secure and cost‑effective storage options.

## Tasks Completed
- Created a Storage Account
- Configured blob containers
- Uploaded and managed files
- Tested hot, cool, and archive access tiers
- Set access levels (private, blob, container)

## Steps Performed

### 1. Created a Storage Account
- Selected region and redundancy options
- Chose performance tier (Standard/Premium)

### 2. Created Containers
- Added containers for organizing data
- Set container access levels

### 3. Uploaded Files
- Uploaded blobs using Azure Portal
- Tested download and access

### 4. Tested Access Tiers
- Moved files between hot, cool, and archive
- Observed cost and performance differences

### 5. Configured Security
- Enabled encryption
- Verified access policies

## Verification
- Files uploaded and accessed successfully
- Access tiers behaved as expected
